FAQ

My NAS doesn't show up.
Turn on Loop Player in Settings › Privacy & Security › Local Network. You can also add the address yourself with the + button on the Network tab.

Subtitles aren't loaded automatically.
Put the subtitle file in the same folder with the same name as the video (movie.mp4 · movie.srt), or with only a language tag added (movie.en.srt).

Videos from Photos don't show up.
Allow access in Settings › Loop Player › Photos.
